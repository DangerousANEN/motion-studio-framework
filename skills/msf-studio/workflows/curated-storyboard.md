# Curated storyboard workflow

Use this workflow when a strong agent must make creative composition choices without writing code.

1. Generate 2–3 scene arcs from stable manifests; explain each arc through intent, data shape and pacing.
2. Choose a single visual language/style kit per section. Introduce contrast only at a deliberate section boundary.
3. Map each scene to a sound-design role; keep background music consistent unless narrative energy intentionally changes.
4. Attach effects only when they clarify hierarchy, motion or transition. Avoid effect stacking for decoration.
5. Validate every draft. Preview the selected arc and revise the shortest possible set of blocks.

Do not expose draft assets or schema escape hatches in this tier.
