ELEMENT BUILDER

Создать и проверить элемент

Сначала preview на валидном runtime contract, затем явный scaffold или регистрация. Браузер не исполняет пользовательский код.

Universal 3D Graph declarative JSON

Сильный агент может описать произвольную сцену из проверенных primitives, групп, GLB/glTF assets, камеры, света и motion. Код в браузере не исполняется.

Выберите image resource. Builder добавит typed resourceId к первому подходящему primitive; произвольные filesystem paths запрещены.

Graph recipe сначала проверяется по типам узлов, лимитам и безопасным параметрам.

Scaffold использует safe area, motion resolver и responsive canvas. После создания откройте файл в IDE, дополните body и запустите registry verify.
