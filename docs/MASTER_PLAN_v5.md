### 0.2 Вердикт vision-анализа текущего рендера

Оценка отрендеренного материала: **3/10 как черновик слайдов, 1/10 как контент для TikTok/Shorts**.

Дословно зафиксированные дефекты:
- «Muddy dark mode» — грязная чёрно-серо-бежевая палитра, нулевой контраст-панч.
- Плоская заливка без света: нет bloom, нет хроматической аберрации, нет градиентных мешей.
- Частицы выглядят «как статичный scatter-plot из Matplotlib», а не как WebGL-поле.
- 3D-стек — «PowerPoint-3D»: выдавленные прямоугольники без фасок, DOF и объёмного света.
- Микроскопический текст (код, лейблы `Feed Forward`/`Attention`) — на телефоне нечитаем.
- Огромные мёртвые зоны, нет фокусной точки, «типографика как в PowerPoint 2012».

**Это и есть корневая проблема.** Пайплайн технически работает (QA fail-closed, реальные проверки
громкости и stddev кадров — это сильная часть). Провал — на уровне визуального языка.

### 0.3 Главные структурные дыры

1. **`Main.tsx` рендерит `<Series>` без единого перехода.** Каждая сцена начинается рывком.
   `@remotion/transitions` даже не установлен.
2. **Установлено всего 4 профильных пакета** из 15+ доступных: `three`, `media-utils`,
   `captions`, `zod-types`. Не установлены (проверено `npm view`, все существуют в `4.0.507`):
   `transitions`, `animation-utils`, `motion-blur`, `shapes`, `paths`, `noise`,
   `layout-utils`, `google-fonts`, `lottie`, `gif`, `skia`, `rive`,
   `install-whisper-cpp`, `whisper-web`, `fonts`, `tailwind-v4`.
3. **Шрифты грузятся гонкой.** `Impact` на Windows-Chromium в headless-рендере не гарантирован,
   кириллица в `Arial Black` рвётся. Нет `@remotion/google-fonts` → нет `waitForFonts`.
4. **`config/default.yml` рассинхронизирован с кодом**: там `fps: 30` и `provider: silero`,
   а реально пайплайн гоняет 60 fps и Qwen3-TTS. Конфиг — ложь.
5. **Нет слоя «сока» (juice)**: ни motion blur, ни зерна, ни виньетки, ни бликов,
   ни тряски камеры, ни speed ramp, ни частиц на удар.
6. **Аудио и картинка не связаны.** Есть звук, есть анимация — но анимация не реагирует
   на амплитуду речи/бита. `@remotion/media-utils` (`useAudioData`/`visualizeAudio`) стоит,
   но не используется.
7. **Субтитры — не караоке.** `TypewriterSub` делит длительность на число слов линейно.
   Реального пословного тайминга от Whisper нет, хотя `@remotion/captions` установлен.

## 2. ПЛАН РАБОТ — 7 ФАЗ

### ФАЗА 1. Фундамент и универсальность
**Цель: убрать хардкод, поднять базу, синхронизировать конфиг.**

1.1 Апгрейд `4.0.506 → 4.0.507`, установка недостающих пакетов:
```bash
npm i @remotion/transitions @remotion/animation-utils @remotion/motion-blur \
      @remotion/shapes @remotion/paths @remotion/noise @remotion/layout-utils \
      @remotion/google-fonts @remotion/lottie @remotion/gif @remotion/fonts
```
1.2 **Починить `config/default.yml`** — привести к реальности (60 fps, Qwen3-TTS) и
    сделать конфиг единственным источником правды; добавить fail-fast при рассинхроне
    конфига и `msf/spec.py`.
1.3 **Слой типографики**: `@remotion/google-fonts` + `waitForFonts()`, чтобы шрифты
    гарантированно загружались до первого кадра. Кириллические дисплейные гарнитуры
    (обязательна проверка glyph coverage перед фиксацией списка).
1.4 **`layout-utils` → авто-фит текста**: `fitText()`/`measureText()` вместо нынешних
    `len > 60 ? '48px' : ...` — текст перестанет ломаться на длинных русских словах.
1.5 Расширить `VideoSpec.schema.ts` + `msf/spec.py` синхронно: слоты под переходы,
    камеру, эффекты, аудио-реактивность.

**Проверка фазы:** `npx tsc --noEmit`, тестовый рендер с длинным русским текстом,
кадры без переполнений.

### ФАЗА 2. Качество картинки — слой «сока» (juice)
**Цель: закрыть ровно те дефекты, которые назвал vision-анализ.**

2.1 **Переходы между сценами.** `Main.tsx`: `<Series>` → `<TransitionSeries>`.
    Подключить 20 презентаций + `springTiming`/`linearTiming`. Переход выбирается
    из спеки, дефолт — осмысленный (не рандом).
2.2 **`<PostFX>` — обёртка пост-обработки** (новый компонент), включаемая через спеку:
    - зерно плёнки, виньетка, bloom/свечение
    - хроматическая аберрация / RGB-split на ударах
    - световые блики (донор — `light-leak-example`)
    - scanlines / CRT — опционально под ретро-стиль
2.3 **`@remotion/motion-blur`** (`<Trail>`, `<CameraMotionBlur>`) на быстрых движениях —
    именно это отличает «дорогой» моушн от дёрганого.
2.4 **Слой виртуальной камеры**: push-in, whip-pan, parallax по слоям глубины,
    тряска, speed ramp. Сейчас камеры нет вообще.
2.5 **Ремонт 3D**: убрать «PowerPoint-3D» — фаски, нормальный свет, DOF,
    плотные WebGL-частицы вместо «scatter-plot».
2.6 **Ремонт палитры**: уйти от «muddy dark mode» к высококонтрастным схемам
    под мобильный экран.
2.7 **Типографическая иерархия**: крупный кинетический заголовок, читаемый на телефоне;
    ликвидация мёртвых зон и микротекста.

**Проверка фазы:** обязательный повторный vision-аудит контрольной полосы кадров.
Цель — уйти с 1/10 на «пригодно для публикации». Без роста оценки фаза не закрыта.

## 5. ЧТО НЕ ЛОМАЕМ

- **Fail-closed QA** в `video_graph.py` — редкая сильная часть, трогаем только на усиление.
- **Публичные API**: `create_video(...)`, `build_msf_graph()` — сигнатуры сохраняются.
- **Контракт camelCase** между `msf/spec.py` и `VideoSpec.schema.ts` — единственный источник правды.
- **Правила Qwen3-TTS** из скилла (ICL, fade, `max_new_tokens`, запрет агрессивных фильтров) — выстраданы.
- **Pop-Laboratory** остаётся фирменным стилем канала.
- Запрет жаргона «SOTA» и порядковых маркеров в текстах для `@llm_hubs`.
