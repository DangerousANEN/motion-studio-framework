# MSF Studio — Политика 3D-ассетов

## Цель

3D-сцены MSF принимают внешний ассет только как **явно переданный** `assetUrl`/`modelUrl` и всегда содержат нативный procedural fallback. Это позволяет сцене быть рендеруемой без чужой модели, но не маскирует лицензионные или сетевые проблемы пустым кадром.

> Для production-рендера агент обязан передать ссылку на GLB/glTF и строку `assetLicense`; отсутствие подтверждённой лицензии — причина оставить procedural fallback или запросить у пользователя совместимый ассет.

## Допустимые источники

| Источник | Условие использования | Что сохранить в проекте |
|---|---|---|
| Пользовательский GLB/glTF | Пользователь владеет моделью или подтверждает право использовать её | Файл, `assetLicense`, attribution при необходимости |
| Sketchfab | Только модель с явно указанной совместимой лицензией и разрешённой загрузкой; не извлекать ассеты из viewer | URL модели, автор, license, attribution, скачанный GLB только при разрешённой загрузке |
| Khronos sample assets | Только ассеты с проверенной лицензией из репозитория/каталога | Имя ассета, ссылка на лицензию и attribution |
| Procedural geometry MSF | Коробки, сферы, линии, частицы и SVG, сгенерированные в renderer | Ничего дополнительно |

Sketchfab указывает, что загружаемые модели поддерживают glTF как стандартный экспорт и публикуются с условиями Creative Commons; это не отменяет проверку конкретной лицензии и attribution для выбранной модели. [1]

## Поля typed contract

| Поле | Назначение |
|---|---|
| `assetUrl` | Абсолютный URL или путь внутри `remotion/public` к `.glb`/`.gltf` ассету |
| `assetLicense` | Лицензия, например `CC0`, `CC-BY-4.0`, `user-owned` |
| `assetAttribution` | Автор и ссылка, когда требует лицензия |
| `cameraPreset` | Allowlisted путь камеры: `orbit`, `arc`, `dolly`, `figureEight` |
| `materialMode` | Allowlisted материал: `original`, `clay`, `glass`, `wireframe` |
| `fallbackShape` | Процедурная фигура, которая покажется при пустом или недоступном ассете |

## Ограничения производительности

Production pipeline должен предпочитать GLB с разумным числом полигонов, PBR-текстурами ограниченного размера и одной моделью на сцену. Постэффекты, число источников света и resolution остаются управляемыми через theme/styleConfig, а не фиксируются внутри модели.

[1]: https://sketchfab.com/features/gltf "Sketchfab — glTF exports"
